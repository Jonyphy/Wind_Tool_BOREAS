Turbine table matcher

Compare two turbine lists by name and position, find turbines that exist in only one list, and copy turbine types from one table to the other.

1

Paste your tables

Copy the rows from Excel and paste them into the boxes. Every row needs a name, easting and northing. Turbine type, hub height and power are optional.

2

Set the matching rules

The defaults suit most wind-farm lists. Results update as you change them.

Separate with commas. # stands for any digit, so V### covers V172 and V199.
Coordinates are read as easting then northing in metres (UTM). Two turbines are the same when their names agree, or when they stand within the tolerance of each other.
3

Review the results

Select a count to filter the table. Turbines that exist in only one table are listed first.
