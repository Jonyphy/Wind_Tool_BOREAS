WTG generator

Paste the power and thrust tables from a manufacturer document, choose the air densities and fill in the turbine data. The tool writes a WAsP / WindPRO .wtg file and checks it before you download it.

1

Performance data

Copy each table from Excel with its header row: wind speed down the side, one column per air density. Both tables in one paste also work, the second one moves to the ct box.

Like the option "Dec. comma accepted" in the WAsP Turbine Editor, here for the pasted data. "Automatic" recognises comma and point by itself. The saved .wtg file always contains decimal points; WAsP shows them as commas or points according to the region setting of the computer.
