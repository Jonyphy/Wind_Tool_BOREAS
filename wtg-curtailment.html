Curtailment WTGs

Paste the curtailment table from a turbulence report. For every curtailed turbine and protected turbine pair the tool writes one .wtg file per wind direction sector, with power and ct set to zero (cut-off) or to a reduced operating mode inside the curtailed wind speed range.

1

Curtailment table

Copy the table from the report with its column breaks. Header lines are skipped. Rows without a curtailed turbine at the start belong to the protected turbine above them.

Turbine types

        

          
One performance table per turbine type: wind speed, power and ct in three columns. Turbines of the same model share one type. A reduced operating mode needs its own table for each type.
