Curtailment WTGs

Paste the curtailment table from a turbulence report. For every curtailed turbine and protected turbine pair the tool writes one .wtg file per wind direction sector, with power and ct set to zero (cut-off) or to a reduced operating mode inside the curtailed wind speed range.

1

Curtailment table

Copy the table from the report with its column breaks. Header lines are skipped. Rows without a curtailed turbine at the start belong to the protected turbine above them.

Like the option "Dec. comma accepted" in the WAsP Turbine Editor, here for the pasted data. "Automatic" recognises comma and point by itself. The saved .wtg file always contains decimal points; WAsP shows them as commas or points according to the region setting of the computer.

Planned turbines

Tick the turbines that are planned (new) in this project. All others count as existing and are not shut down in the worst case. Where an existing turbine is curtailed for a planned one, the planned turbine is curtailed instead in the worst case, with the same sector and speeds. Nothing ticked: all rules are used as one set of files.

Advanced: also curtail an existing turbine to protect a planned one (best case)

Creates an extra best case file for the ticked pair. The sector and the speed range are the same as in the table rule.

Turbine types

        

          
One performance table per turbine type: wind speed, power and ct in three columns. Turbines of the same model share one type. A reduced operating mode needs its own table for each type. A new type copies rotor, hub height and density from the previous one, so you only change what differs.

Names and types

        

          
Short names are used in the file names and are remembered in this browser. Assign each curtailed turbine to one of your types.

          
IdentifierRoleShort nameType

          

            
            
Start speeds go down and stop speeds go up to the nearest table speed. A tolerance above 0 treats a table speed that close to the reported value as equal, for example 7.99 for 8.0.
